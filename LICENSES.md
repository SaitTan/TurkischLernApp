# Lizenzen verwendeter Inhalte

## Sounds (`app/src/main/res/raw/sfx_*`)

Die meisten Sounds sind eigene, per additiver Synthese erzeugte Töne
(Marimba-/Glocken-Klang), erzeugt mit `tools/gen_sounds.py`.

`sfx_correct.mp3`, `sfx_wrong.mp3` und `sfx_celebrate.mp3` wurden vom Projektinhaber
beigesteuert.
Vor einer Veröffentlichung der App muss deren Herkunft und Lizenz geklärt werden.

| Datei | Klang |
|---|---|
| sfx_tap.wav | weiches „Plopp“ beim Antippen |
| sfx_correct.mp3 | Prüfungs-Ton bei richtiger Antwort (beigesteuert) |
| sfx_wrong.mp3 | Prüfungs-Ton bei falscher Antwort (beigesteuert) |
| sfx_kangal_correct.mp3 | Kangal-Stimme bei richtiger Antwort (beigesteuert) |
| sfx_kangal_wrong.mp3 | Kangal-Stimme bei falscher Antwort (beigesteuert) |
| sfx_celebrate.mp3 | Maskottchen beim Lektions-Abschluss (beigesteuert) |
| sfx_combo.wav | Glitzer-Ton (Tonhöhe steigt mit der Combo) |
| sfx_xp_tick.wav | kurzes Klicken beim Hochzählen |
| sfx_badge.wav | Glitzer-Arpeggio |
| sfx_streak.wav | warmer, aufsteigender Dreiklang |
